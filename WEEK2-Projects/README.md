## WEEK2 : BabySoC Fundamentals &amp; Functional Modelling

As part of my **RISC-V Tapeout Program learning journey**, this week I focused on the **fundamentals of SoC design** and the **functional modelling of BabySoC**. The aim is to connect theory with practice and understand how individual components of a SoC interact in simulation.

### What I worked on this week

* **Conceptual Understanding (Theory):**

  * Basics of SoC architecture and design flow.
  * Role of functional modelling in verifying system behavior before synthesis.

* **VSDBabySoC Project**

This document provides a comprehensive guide for the VSDBabySoC project, a compact System-on-Chip (SoC) design integrating:

the RVMYTH RISC-V processor core,a Phase-Locked Loop (PLL) module, and a 10-bit Digital-to-Analog Converter (DAC).
- It covers project setup, module descriptions, pre-synthesis and post-synthesis simulations, synthesis using Yosys, troubleshooting, and error resolution.
  
- Key Highlights:
  
-- Simulating BabySoC modules using Icarus Verilog.

-- Observing signal behavior and verifying functionality with GTKWave.

-- Generating gate-level netlists and performing post-synthesis verification.
 



This week builds my foundation in **SoC design and verification** while giving me **practical exposure to simulation tools** used in real tapeout flows.
